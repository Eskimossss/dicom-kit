## Координация и границы

`StorageCoordinator.maintenance` сериализует полный индекс, удаление и переключение хранилища с приёмом. Приём держит read gate до публикации одного metadata record; независимые SOP сохраняют параллелизм. Порядок locks — coordinator → index lock. Миграция по-прежнему использует безопасную проверку каждого файла и per-SOP gate, без глобальной блокировки всего пакета. Повторные refresh во время текущей архивной задачи объединяются; другая архивная команда отклоняется с понятным сообщением, а не выполняется скрытно.

Ownership ledger сохраняется безопасно целиком, поэтому его обновление тоже зависит от размера архива; отдельное исследование с десятками тысяч объектов требует измерения на устройстве. Snapshot остаётся в памяти; после рестарта индекс строится заново. CPU-пересборка затронутого исследования и immutable списков всё ещё зависит от числа его экземпляров; дискового пересканирования архива при каждом C-STORE больше нет. Монитор retained incoming и проверка доступности хранилища работают в независимых IO jobs: блокировка SAF или миграция не скрывает накопление .incoming_tmp/*.part. Публикация проверенной информации защищена generation gate, поздняя проверка прежнего каталога не подменяет новую конфигурацию и свежий retained counter. Android-регрессия создаёт синтетическую часть при заблокированном provider и ждёт предупреждение до release provider, затем проверяет сохранение счётчика. Некооперативный DocumentsProvider может задержать завершение фоновой операции; UI показывает ожидание, новый небезопасный запуск блокируется. Приложение не обещает, что Android/OEM позволит приём круглосуточно.

P2-02 остаётся **частично исправленным**: большая ViewModel не полностью разделена, общий typed-event/use-case слой не вводился. WW/WL, выбранный внешний URI, Bitmap и очередь не сериализуются для автоматического возобновления после process death. Безопасное поведение — новый экран приёмника, повторная индексация, сохранённые AE/порт и настройки PACS, журнал прежних результатов; повтор SCU только вручную. Масштабная переработка ради устранения структурного долга в этот этап не включена.
