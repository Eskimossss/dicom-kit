## Изменения

| Замечание | Результат |
|---|---|
| Системный Back немедленно закрывает Activity | На основных вкладках требуется второй Back в течение двух секунд, первый показывает подсказку. Во вложенном экране/полноэкранном Viewer сначала обычный возврат. Запущенный SCP останавливается собственной кнопкой, закрытие Activity само по себе не выключает службу |
| Точные повторы приняты, но счётчик остаётся 1 | Добавлены три режима. По выбранному пользователем умолчанию каждый сетевой приём сохраняется отдельным файлом. DEDUPLICATE подтверждает имеющуюся копию без роста; REJECT_IDENTICAL возвращает ошибочный C-STORE-RSP. Сравнение полных байтов потоковым SHA-256, а не только UID/размера. Разные данные одного UID всегда остаются отдельно |
| Неясный результат хранения в журнале | Добавлены явные NEW_COPY / REPEAT_COPY / DUPLICATE_CONFIRMED / CONTENT_COLLISION. Подтверждение имеющейся копии действительно не увеличивает число файлов. До сравнения содержимого данные нужно принять по сети; запись C-STORE-RQ сама по себе не означает создание новой копии |
| Папки названы цифрами | Это Study/Series/SOP Instance UID. Добавлена отдельная настройка «ФИО + UID для папок новых исследований». ФИО очищается от небезопасных символов, UID остаётся для различения исследований. Старые папки и файлы не переименовываются, продолжение существующего исследования использует прежнюю папку. Настройка выключена по умолчанию; ФИО в пути явно помечено как персональные данные |
| После очистки остаются пустые SAF-папки | Преднамеренное ограничение безопасной очистки: удаляются проверенные собственные документы, неизвестные каталоги не удаляются рекурсивно. Объяснение добавлено рядом с кнопкой. Файлы/исследования 0 означает отсутствие индексированных исследований, а не отсутствие каталогов |
| Красное предупреждение .incoming_tmp | Активные временные файлы исключены из счётчика оставленных источников. После ошибки/прерывания неактивные источники остаются видимыми; обычная очистка их сохраняет. Добавлена явная команда повторного сохранения. Полный структурный разбор выполняется без загрузки bulk в память; фактическое чтение вместо seek за EOF обнаруживает усечённый Pixel Data. Копия проверяется по содержимому, непроверенные источники остаются на месте |
| WW/WL неудобны | Во всех общих viewport добавлены WL−/WL+. Шаг кнопок WW/WL и кнопок возле ползунков — около 5% текущего WW, минимум 1. Убран повторный множитель шага в ViewModel. WW управляет шириной окна/контрастом, WL — центром окна/яркостью; действие зависит также от инверсии/фотометрии. «Авто Мин/Макс (WW/WL)» строится по диапазону текущего кадра, числа не являются диагностикой. Пояснение отображается в UI |
| В безопасном кратком экспорте нет меток SCP | Закрытая проекция разрешает только строго проверенные SCP-N/SCU-N; дополнительно есть локальный номер сеанса экспорта. Произвольный текст, исходные timestamps, AE/IP, пути и UID экземпляров не возвращаются в безопасный экспорт. Юридическая анонимизация не гарантируется |
| Узел исчезает после C-ECHO | История успешных ассоциаций по AE+IP остаётся до остановки сервера, повторный запрос обновляет последнее время. Счётчик действующих соединений остаётся отдельным. После нового запуска история очищается; исправлена гонка обновления старого snapshot. История ограничена последними 256 узлами и не означает ONLINE |

Миграция и явное восстановление по-прежнему объединяют точные повторы в одну проверенную копию; это не режим сохранения каждого сетевого повтора. UI прямо описывает различие. Ошибка удаления исходника не превращается в потерю данных: источник остаётся и отображается монитором.

Для 16-bit bitmap тест явно ждёт нового значения пикселя после асинхронного рендера; сравнение старого bitmap приводило к промежуточному падению. JVM обнаружил гонку сброса истории (исправлена) и прежний performance-порог журнала (201/249 мс при лимите 200). Убрана повторная компиляция неизменяемых Regex в группировщике; порог не увеличивался, тест не отключался.
